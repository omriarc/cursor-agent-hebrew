# עברית ב-Cursor Agent

[English](README.md)

עברית בטרמינל של Cursor Agent נקראת מימין לשמאל. אנגלית נשארת משמאל.

Agent מצייר את המסך תא אחרי תא, משמאל לימין. עברית נשמרת כך שהאות הראשונה היא הראשונה בקובץ, ולכן מילה כמו `היי` הופיעה עם `ה` בצד שמאל. המשגר הזה מסדר את התאים מחדש לפי אלגוריתם הכיווניות של יוניקוד, רגע לפני הציור.

הטקסט שהמודל כותב לא משתנה. התיקון יושב מחוץ להתקנת Agent, בתיקייה `~/.local/share/cursor-hebrew`.

## התקנה

Cursor Agent צריך להיות מותקן מראש (`agent` עובד בטרמינל).

```bash
git clone git@github.com:omriarc/cursor-agent-hebrew.git
cd cursor-agent-hebrew
./install.sh
```

פותחים טרמינל חדש ומפעילים את `agent` מחדש.

## אחרי עדכון של Agent

עדכון מחליף את גרסת Agent ומחזיר את קיצור הדרך המקורי של `agent`. הטרמינל הבא מחזיר את המשגר ומפעיל עברית על הגרסה החדשה לפני ש-Agent עולה.

## מה רואים

- שורה בעברית נקראת מימין.
- שורה באנגלית נשארת משמאל.
- מספר בתוך עברית, למשל `12`, נשאר `12`.
- בזמן הקלדה הסמן יכול לשבת בקצה של מילה בעברית. האותיות עצמן בסדר הנכון.

אם גרסה עתידית של Agent תצייר את המסך אחרת, ההתקנה משאירה את העברית כמו שהיא ומדפיסה שורה אחת, במקום לשבור את Agent.
